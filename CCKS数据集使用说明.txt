🚀 快速使用
==================================================

步骤1: 训练模型
--------------------
python train_ccks.py

配置:
  • BERT: bert-base-chinese
  • 训练轮数: 10 epochs
  • 学习率: 2e-5
  • Batch Size: 4
  • 训练/验证: 90%/10%

预计训练时间:
  • CPU: 2-4小时
  • GPU: 30-60分钟

步骤2: 预测测试集
--------------------
python predict_ccks.py \
    --input ccks_task2_eval_data.txt \
    --output predictions.txt \
    --model checkpoints/best_model.pt \
    --threshold 0.3

参数说明:
  --input     输入文件(测试集)
  --output    输出文件
  --model     模型路径
  --threshold 置信度阈值(0-1)

步骤3: 查看结果
--------------------
head -10 predictions.txt

输出格式与训练集相同,包含预测的因果关系。

💡 性能优化建议
==================================================

1. 调整超参数
--------------------
# 修改 train_ccks.py
num_epochs = 20      # 增加训练轮数
learning_rate = 1e-5 # 降低学习率

2. 调整模型结构  
--------------------
# 修改模型初始化
num_gnn_layers = 4   # 增加GNN层数
num_heads = 8        # 增加注意力头数

3. 调整预测阈值
--------------------
--threshold 0.5  # 高精度,低召回
--threshold 0.2  # 高召回,低精度
--threshold 0.3  # 平衡(推荐)

4. 数据增强(高级)
--------------------
• 同义词替换
• 回译增强
• 规则过滤

==================================================

Q: 模块找不到

A: 设置镜像源或手动下载

Q: 内存不足
A: 减小batch_size到2或1

A: 降低threshold阈值

Q: 训练太慢
A: 使用GPU或减少数据量
