   Impact: 60-70% of pairs pass this threshold

   Location: causality_extraction.py, Lines 683-687
   Impact: N events → N*(N-1) pairs
   Example: 10 events = 90 possible pairs
   Quick Fix: Use only heuristic-connected edges
   Expected Reduction: 40-60% of pairs

3. AGGRESSIVE EVENT EXTRACTION
   Location: predict_ccks_improved.py, Lines 48-119
   Impact: Extracts 8-10 events per sample
   Problem: Keyword matching finds ALL occurrences
   Quick Fix: Reduce to 6-7 max, limit occurrences
   Expected Reduction: 30-40% fewer events

4. WEAK EDGE FILTERING
   Location: causality_extraction.py, Line 608
   Impact: 0.3 confidence threshold allows unrelated pairs
   Quick Fix: Change to 0.5+
   Expected Reduction: 20-30% of edges

MEDIUM-PRIORITY ISSUES:

5. BIDIRECTIONAL DOUBLE-COUNTING
   Location: causality_extraction.py, Lines 696-716
   Impact: Same relationship counted from both directions
   Example: (A→B) from pair (A,B) and (B→A) from pair (B,A)
   Expected Reduction: 10-15% of predictions

6. UNDER-TRAINED MODEL
   Location: train_ccks.py, Line 381
   Impact: Only 10 epochs → underfitting
   Expected after 20+ epochs: Better discrimination

5. PREDICTION PIPELINE FLOW
================================================================================

Input: Test sample (text_id, text)

Step 1: EVENT EXTRACTION
  - Keyword matching (all occurrences)
  - Fallback: sentence splitting
  - Deduplication by (text, type)
  - Output: 8-10 events

Step 2: PAIR GENERATION
  - Create all pairs: (i, j) for all i ≠ j
  - Output: 56-90 pairs per sample
  → PROBLEM: Cartesian product explosion

Step 3: BERT ENCODING
  - Encode each event
  - Output: N × 768 tensor

Step 4: GRAPH CONSTRUCTION
  - Build initial graph using heuristic rules
  - Filter edges with confidence > 0.3
  - Extract edge features (11 dims)
  → PROBLEM: 0.3 threshold too permissive

Step 5: GNN FORWARD PASS
  - 3-layer GAT processing
  - Edge gating mechanism
  - Output: updated event representations

Step 6: CLASSIFICATION
  - MLP classifier on event pairs
  - Softmax outputs (3 classes)
  - Output: probabilities

Step 7: THRESHOLD FILTERING
  - if pred_class < 2 AND confidence > 0.3:
  - Create causal pair
  → PROBLEM: 0.3 threshold + 3 classes = 60-70% pass rate

Step 8: OUTPUT
  - List of causal pairs
  - Output: 21,839 predictions (vs 7,886 expected)
