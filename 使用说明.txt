🎯 核心功能
-------------------------------------------------

1. 启发式规则 (3.2.1节)
   - 词汇触发规则: 强/弱触发词识别
   - 句法依存规则: 依存路径模式
   - 语义角色规则: AM-CAU角色识别
   - 规则整合: 最大置信度选择

2. 图神经网络 (3.2.2节)
   - 多层GAT: 3层,每层4个注意力头
   - 边置信度门控: 动态调节边权重
   - 多头消息传递: 多视角因果建模
   - 层级更新: 逐层特征聚合

3. 分类器 (3.2.3节)
   - MLP分类: 3类输出(原因/结果/无关系)
   - Focal Loss: 处理类别不平衡

💻 代码示例
-------------------------------------------------

from causality_extraction import CausalExtractionModel, CausalEvent

# 初始化模型
model = CausalExtractionModel()

# 准备数据
text = "央行加息导致股市下跌"
events = [
    CausalEvent(text="央行加息", start_pos=0, end_pos=4,
               event_type="政策", arguments={}),
    CausalEvent(text="股市下跌", start_pos=6, end_pos=10,
               event_type="市场", arguments={})
]

# 预测因果关系
pairs = model.predict(text, events)

# 输出结果
for pair in pairs:
    print(f"{pair.cause.text} → {pair.effect.text}")

📖 主要类说明
-------------------------------------------------

1. HeuristicRules
   - 实现三类启发式规则
   - 计算初始边权重

2. EdgeFeatureExtractor
   - 提取5类边特征(11维向量)
   - 包括距离、相似度、连接词等

3. CausalGNN
   - 图注意力网络
   - 实现算法1的更新机制

4. CausalRelationClassifier
   - MLP分类器
   - Focal Loss计算

5. CausalExtractionModel
   - 完整的端到端模型
   - 整合所有组件
